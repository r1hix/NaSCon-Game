## 🎮 Game Concept

**Umbra Chronos** is a 2D atmospheric puzzle-platformer where **celestial light is lethal radiation**, and **shadows are physical, solid matter**. 

By turning the **Celestial Sundial**, the player rotates the light source across the sky, stretching, bending, and solidifying dynamic shadows into traversable bridges, climbable towers, and protective shelters. When puzzles demand more than one person, the **Tape-Reel Rewind** lets you turn back time while leaving your past self behind as an **Umbral Echo**—a tangible shadow clone that replicates your past actions.

---

## 🌟 The Themes: Time & Shadow Synergy

* **Theme Adherence (30% Evaluation Weight):**
  * **Core Integration (15 pts):** Time is the literal input axis. Scrubbing the celestial clock forward or backward drives every environmental change and physical path.
  * **Multi-Theme Synergy (10 pts):** Shadows cannot exist without light, and light cannot move without Time. Shadows are generated by Time, solidified by Time, and your previous timeline is literally your Shadow.
  * **Atmospheric Framing (5 pts):** A high-contrast aesthetic—inky black geometric silhouettes set against shifting celestial skies (dawn, dusk, eclipse) accompanied by ticking clockwork soundscapes.

## 🕹️ Core Mechanics

| Mechanic | Input | Gameplay Description |
| :--- | :--- | :--- |
| **Move & Jump** | `A` / `D` or `Arrow Keys` + `Space` | Snappy, responsive 2D platforming with coyote time and jump buffering. |
| **Celestial Sundial** | `Q` / `E` or `Mouse Wheel` | Rotates the celestial light source around the sky. Monoliths dynamically cast physical shadow bridges across deadly chasms of sunlight. |
| **Tape-Reel Rewind** | `R` or `Left Shift` (Hold) | Rewinds the state of the player, platforms, and world along a 5-second circular timeline buffer with retro tape-stop audio and chromatic aberration. |
| **Umbral Echo** | `E` or `Space` (During Rewind) | Rewinds your player while anchoring an **Umbral Echo** (shadow clone) that replays your last 5 seconds of actions (holding pressure plates, opening gates). |

## 🛠️ Tech Stack & Engine Requirements

* **Game Engine:** Unity 6 (`6000.6.3f1` / `6000.6.x LTS`).
* **Pipeline:** Universal Render Pipeline (URP) with 2D Renderer.

* **Audio:** Ambient modular synth, reverse tape-stop SFX, stone impact chiptones.
* **Development Environments:**
  * macOS (Apple Silicon arm64)
  * Windows 11 (x86_64)

## 🚀 Setup & Developer Guide

### 1. Cloning the Repository
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd GameDev
```

### 2. Opening in Unity 6
1. Open **Unity Hub**.
2. Click **Add &rarr; Add project from disk**.
3. Select this folder (ensure Unity version `6000.6.3f1` or `6000.6.x` is selected).
4. Verify under **Edit > Project Settings > Editor**:
   * **Asset Serialization:** `Force Text`
   * **Version Control:** `Visible Meta Files`

### 3. Team Collaboration Workflow (No Scene Conflicts!)
* **Do NOT work in the same scene file.**
* Work inside personal sandbox scenes:
  * Shaf (Mac): `Assets/_Project/Scenes/Sandboxes/Sandbox_Shaf.unity`
  * Partner (Win): `Assets/_Project/Scenes/Sandboxes/Sandbox_Partner.unity`
* **Everything is a Prefab:** Save player, mechanics, and interactive props as Prefabs in `Assets/_Project/Prefabs/`. When you update a prefab and push to Git, your teammate's scene will automatically receive the updates without merge conflicts.
* Always pull before starting work: `git pull --rebase origin main`.
